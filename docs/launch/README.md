# Launch kit

This directory contains **draft material for the first alpha**. Do not announce the package as available until its registry installation has been verified.

## Release readiness

- [ ] Final logo and wordmark reviewed; small and large uses remain legible.
- [ ] License, public contact address, README files, docs, and contributor templates reviewed.
- [ ] Release changes merged into `main` and required checks passed.
- [ ] Repository made public with the owner's authorization; public links checked while signed out.
- [ ] Exact npm artifact inspected and installed; alpha published and installed again from the registry.
- [ ] Version, dist-tag, source commit, validation limits, and release notes agree.
- [ ] GitHub pre-release and announcement links point to actual published pages.
- [ ] Screenshots/demo use the released CLI and expose no credentials or private paths.

## Prepared material

- [English and Chinese announcement drafts](announcement.md)
- [Short demo recording script](demo.md)
- [Brand story and usage notes](brand.md)

Lead with the workflow and a runnable example. Explain that npm distributes jpm, while Maven still resolves Java dependencies and builds the application. Avoid unsupported claims about speed, full npm compatibility, production readiness, offline installs, or replacing Maven.

Publication, repository visibility, and posting an announcement are separate decisions. Preparing this kit does not post it anywhere.
